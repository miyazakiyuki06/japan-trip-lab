# JAPAN TRIP LAB · 일본 여행 실험실

일본 여행을 **도시·시기·예산**으로 비교하는 한국어 Streamlit 앱.

## 기능
- 도쿄·오사카·나고야·후쿠오카·삿포로·나하의 월별 기후 비교
- 도시 다중 선택, 여행 월, 선호 기온·강수량 필터
- 산점도, 월별 선 그래프, 도시×월 히트맵
- 사용자가 정한 단가·환율로 여행 예산 계산 및 체류 일수별 민감도 분석
- 필터된 기후 데이터와 예산표 CSV 다운로드
- 빈 도시 선택 안내, 데이터 출처·단위·가정 명시

## 실행
Python 3.13에서 검증합니다.

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Streamlit Community Cloud 배포
1. 이 폴더의 파일을 새 GitHub 저장소 루트에 업로드합니다. `data/climate.csv`와 `.streamlit/config.toml`도 포함합니다.
2. https://share.streamlit.io/ 에서 로그인하고 **Create app**을 선택합니다.
3. 해당 GitHub 저장소, `main` 브랜치, `app.py`를 지정합니다.
4. Advanced settings에서 Python 3.13을 선택하고 Deploy를 누릅니다.
5. 공개 URL에서 도시 선택·예산 변경·CSV 다운로드를 확인합니다.

API 키나 Secrets는 필요하지 않습니다. `build_data.py`는 번들 CSV를 재생성하는 도구이며 배포 시 실행할 필요가 없습니다.

## 데이터와 계산
기후: 일본 기상청(JMA), 1991–2020 평년값.
https://www.data.jma.go.jp/stats/data/en/normal/normal.html
확인일: 2026-11-19. 원문 중 6개 관측소의 월평균 기온과 월 강수량을 전사한 72행.
기후 평년값은 예보가 아니며, 강수량은 강수확률이 아닙니다.

비용·환율 초기값은 교육용 가정으로 현재 시장 가격이 아닙니다. 1인 여행, 숙박은 여행 일수보다 1박 적게 계산합니다.

`현지 비용 = 숙박 단가 × (일수−1) + (식비 + 교통비 + 관광비) × 일수`

`총비용 = (현지 비용 × 100엔당 원화/100 + 왕복 항공료) × (1 + 예비비 비율/100)`

도시·월 선택은 기후 비교에만 적용됩니다. 예산에는 도시별 가격 차이나 계절 할증을 임의로 넣지 않았습니다.
